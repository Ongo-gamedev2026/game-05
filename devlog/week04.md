## 3️⃣ 추가 · 수정 요청 기록

> ver1을 보고 Gemini에게 보낸 요청을 **보낸 순서대로** 적어요. **🎮 → 9단계**에서 Word 파일을 올리면 자동으로 채워져요.
> 종류: **추가**(새 기능 넣기) / **수정**(있는 것 바꾸기) / **버그**(원하는 대로 동작하지 않음)

| 종류 | 🗣️ 요청한 내용 | 결과 | 🔧 남은 문제 |
|---|---|:---:|---|
| 수정 | 캐릭터 이동 시 점선 포물선 표시, 게이지 위치 변경 및 시각적 퀄리티 향상을 요청함 | ❓ 확인 필요 |  |
| 버그 | 얼음판을 점프해 올라갈 때만 통과되고 착지 시에는 통과되지 않고 착지되도록 수정을 요청함 | ❓ 확인 필요 |  |
| 수정 | 맵 길이 확장, 포물선 착지 구간 표시, 부채꼴 점프바 구현 및 전체 퀄리티 향상을 요청함 | ❓ 확인 필요 |  |
| 수정 | 플로팅 부채꼴 게이지와 포물선 궤적 조준선이 적용되었던 이전 버전으로 롤백을 요청함 | ❓ 확인 필요 |  |
| 수정 | 점프할 때 뜨는 바를 원 모양 대신 부채꼴로 변경하고 부채꼴 중앙에 맞춰야 점프력과 안정성이 높아지도록 수정을 요청함 | ❓ 확인 필요 |  |
| 추가 | 맵 길이를 늘리고 점프 후 착지 지점 포물선 표시 및 좌측 상단 현재 높이 표시를 요청함 | ❓ 확인 필요 |  |
| 수정 | 몰려 있는 플랫폼을 좌우로 배치하고 캐릭터 모션 애니메이션 추가를 요청함 | ❓ 확인 필요 |  |
| 추가 | 상점 플랫폼 밟을 시 1회 강제 퍼펙트, 시간 역행, 점프력 증가 중 선택하는 상점 기능 추가를 요청함 | ❓ 확인 필요 |  |
| 수정 | 상점의 영구 점프력 증가 아이템 수치를 15%에서 5%로 변경을 요청함 | ❓ 확인 필요 |  |

| 🙋 Gemini의 질문 | ✍️ 내 답 | 💡 그래서 정한 것 |
|---|---|---|
| 이 게임에서 플레이어가 가장 재미있고 짜릿함을 느껴야 하는 순간은 정확히 언제라고 생각해? | 플레이어가 연속 퍼펙트로 시원하게 올라가는 짜릿함과 끝까지 올라간 성취감이다. | 연속 퍼펙트 콤보 시스템 및 클리어 연출 강화 |
| 맵 구조나 기믹(얼음판, 용암판, 게이지 속도 등) 중에서 플레이어가 느끼기에 너무 어렵거나, 반대로 너무 싱겁다고 생각되는 부분은 어디야? | 얼음판에서 예상보다 덜 미끄러져 아쉬웠고 용암판에 올라갔을 때 속도가 너무 빨랐다. | 얼음판 미끄러짐/추락 물리 밸런스 조정 및 용암판 게이지 속도 조절 |
| 이 게임을 처음 해보는 친구가 게임을 켰을 때 어떤 부분에서 가장 헷갈리거나 적응하기 어렵다고 느낄 것 같아? | 얼음판과 용암판에 설명이 없고 그래픽이 정확하지 않아서 잘 모를 것 같다. | 특수 발판(얼음·용암) 그래픽 이펙트 강화 및 안내 문구 추가 |

| 다음 버전(ver3) 개발에서 가장 먼저 구현해야 할 핵심 과제는 무엇이라고 생각해? | 2번(연속 퍼펙트 콤보 & 물리 밸런스) -> 3번(맵 미세 조정 & 클리어 연출) -> 1번(특수 발판 그래픽 & 안내 문구) 순서로 진행한다. | ver3 개발 우선순위를 1순위 연속 퍼펙트 콤보 및 물리 밸런스, 2순위 맵 미세 조정 및 클리어 연출, 3순위 특수 발판 그래픽 및 안내 문구로 확정 |
